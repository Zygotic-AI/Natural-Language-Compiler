# Public packs, signing, and registering

**Summary**

Still ahead: a registered group can publish a signed pack that installs into your graph as constraints the compiler enforces.

**Paragraph**

Still ahead, after other languages. A group registers with the NLC effort, confirms an email, and uploads a signed bundle that is checked file by file before it is listed. You install a pack someone else published, and it enters your graph as constraints the compiler enforces in the codebase it manages. How a stolen signing key is retired, and how a legitimate group rotates a key, has to be solved before this ships. The audit of a pack is the same kind of review as the audit of your code: follow the signature to the constraints, then follow the graph to the code.
